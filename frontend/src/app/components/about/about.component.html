About eth.tx.taxi

eth.tx.taxi adapts the familiar Mempool explorer interface for Ethereum. It presents public Ethereum blocks, transactions, account balances, gas prices, and pending transaction activity in a consistent tx.taxi experience.

Data sources

The explorer reads public Ethereum data through a small compatibility adapter backed by public Blockscout endpoints. Provider fallbacks keep the interface useful when one upstream endpoint is unavailable. Values shown here are observations from those providers, not independent consensus verification.

Open-source lineage

The interface is a modified fork of mempool/mempool and remains available under the GNU AGPLv3. Ethereum-specific terminology, data mapping, and tx.taxi branding are maintained separately.
